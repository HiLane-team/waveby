# Waveby

**길에서 스쳐 지나간 차들의 캐릭터가 주차하면 내 공원에 놀러 오는 Pleos Connect 앱**

팀 HiLane · 패키지 `com.drivepark.app` · 버전 0.1.0

> ⚠ **시연용 데이터 안내:** 1차 제출본은 실제 다른 차량과 통신하지 않습니다. 주행 중 "만난" 친구 캐릭터(닉네임·인사말·생김새)는 모두 앱 안에서 무작위로 만든 **가짜 데이터**입니다(`FakeEncounterSource`). 실제 차량 간 매칭은 2단계에서 서버로 붙일 예정입니다.

---

## 1. 앱 소개

주행하는 동안 Waveby는 화면을 차지하지 않습니다. 순정 내비 위에 작은 팝업으로 내 캐릭터가 걷는 모습만 보여 줍니다. 기어를 P로 바꾸면 그동안 스쳐 간 친구들이 한꺼번에 공원에 도착하고, 음성으로 짧은 도착 인사를 들려줍니다.

### 주요 기능
| 기능 | 설명 |
|---|---|
| 초기 설정 5단계 | 환영 → 권한 → 내 캐릭터 만들기(닉네임 10자, 인사말 30자) → 취향 → 완료 |
| 시동 인사 | 앱을 켜면 시간대에 맞는 인사를 띄우고, 내비로 갈지 공원에 머물지 고릅니다 |
| 주행 팝업 | 주행(D) 중 내비 위에 터치를 받지 않는 작은 팝업만 표시합니다. 주행 중 앱을 열면 조작을 막습니다 |
| 주차 시 도착 | 기어 P가 되면 모인 친구를 공원에 전달하고, 알림과 음성(TTS)으로 알려 줍니다 |
| 지역 도감 | 횡성·보성·제주·강릉·영덕에서 주차하면 지역 캐릭터를 모읍니다 |
| 공원 | 도트 캐릭터가 걸어 다니는 공원. 라이트/다크/시스템 테마와 밤 공원을 지원합니다 |
| 사색 모드 | "잠깐 사색에 잠기기"를 켜면 만남 수집을 멈춥니다 |
| 주차 10분 뒤 공원 띄우기 | 주차 후 10분이 지나면 공원을 다시 띄웁니다(설정에서 끌 수 있음) |
| 3분할 화면 대응 | Pleos 분할 화면의 좁은 칸에서도 배치가 맞게 바뀝니다 |

### 개인정보 원칙
- 만남은 **주차할 때 모아서** 전합니다. 주행 중에는 몇 명을 만났는지도 보여 주지 않습니다.
- 언제·어디서 만났는지는 저장하거나 보여 주지 않습니다. 위치는 지역 도감을 판정할 때만 한 번 씁니다.

### 사용한 Pleos Connect SDK
| SDK | 버전 | 쓰임 |
|---|---|---|
| Vehicle | 2.3.2 | 기어 상태(P/D) 구독 → 주행/주차 판단 |
| FusedLocation | 1.1.3 | 주차 위치로 지역 도감 판정 |
| TextToSpeech | 3.3.1 | 도착 인사·브리핑 음성(온디바이스, ko_KR) |
| NaviHelper | 2.0.3 | 시연용 순정 내비 경로 요청 |
| LLM (글레오) | 2.1.3.2 | **추가 기능.** 도착 브리핑 문장 생성. 응답이 없으면 3초 뒤 정해진 문장을 읽습니다 |

> 에뮬레이터 v2.1.0에서는 온디바이스 LLM이 꺼져 있어, 브리핑은 정해진 문장으로 나옵니다(정상 동작).

## 2. 실행 방법

### 제출된 APK로 바로 실행 (권장)
```bash
adb install -r apk/HiLane_Waveby_release.apk
adb shell appops set --user 10 com.drivepark.app SYSTEM_ALERT_WINDOW allow   # 주행 팝업 권한
```
앱 목록에서 **Waveby**를 실행합니다.

> Pleos Connect 에뮬레이터에서 앱은 사용자 10으로 실행됩니다. 이 에뮬레이터에는 "다른 앱 위에 표시" 설정 화면이 없어서, 주행 팝업 권한은 위 `appops` 명령으로 켭니다.

### 소스에서 빌드
Android Studio로 폴더를 열면 SDK 경로가 자동으로 잡힙니다. 터미널에서 빌드할 때는 `ANDROID_HOME`(또는 `local.properties`의 `sdk.dir`)에 Android SDK 경로를 지정해 주세요.
```bash
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # 단위 테스트
```
- 개발용 빌드는 패키지가 `com.drivepark.app.debug`, 앱 이름이 "Waveby (개발)"이라 제출본과 함께 설치됩니다. 주행 팝업 권한도 이 패키지 이름으로 따로 켜야 합니다.
- release 서명 키는 저장소에 포함하지 않았습니다. 키 없이 `assembleRelease`를 하면 서명되지 않은 APK가 나오니, 실행 확인은 제출된 APK나 debug 빌드로 해 주세요.
- Pleos SDK는 `settings.gradle.kts`에 등록된 Pleos Playground Maven 저장소에서 내려받습니다(인증 없음).

### 시연 순서
1. 처음 실행하면 초기 설정 5단계를 진행합니다. 권한은 위치·알림을 허용합니다.
2. Virtual Console에서 기어를 **D**로 바꾸면 내비 위에 주행 팝업이 뜹니다.
   ```bash
   adb forward tcp:8088 tcp:8088   # 이후 PC 브라우저에서 http://127.0.0.1:8088/
   ```
3. 기어를 **P**로 바꾸면 친구들이 공원에 도착하고 음성 인사가 나옵니다.
4. 기어를 바꾸기 어려우면 **개발자 메뉴**를 쓰세요: 설정 → 앱 정보의 "버전" 줄을 5번 누르면 열립니다.
   - **드라이브 시뮬레이션 실행:** 친구 0~5명 도착을 바로 재현합니다.
   - **순정 내비 모의 주행 / 주차:** 기어 상태를 앱 안에서 덮어씁니다.
   - **음성 테스트**, **공원 띄우기 시험(5초)**
5. 지역 도감을 확인하려면 위치를 지역 안으로 옮긴 뒤 주차합니다. 예: 횡성 `adb emu geo fix 127.98 37.49`

## 3. 테스트 환경 및 필요한 설정

| 항목 | 값 |
|---|---|
| 에뮬레이터 | Pleos Connect v2.1.0 (API 34) |
| 권장 실행 | `emulator -avd Pleos_Connect_v2_1 -no-snapshot-load -memory 4096 -gpu host` (Cold boot 필요, Quick boot면 차량 기능을 쓸 수 없음) |
| 앱 요구 사항 | minSdk 28 / targetSdk 36 / compileSdk 37, 차량(automotive) 기기 전용 |
| 빌드 도구 | Android Studio 내장 JDK(JBR), Gradle 9.8.2(wrapper), AGP 9.5.0, Kotlin 2.4.21 |
| 런타임 권한 | 위치(`pleos.car.permission.FUSED_LOCATION`), 알림(`POST_NOTIFICATIONS`) — 초기 설정 2단계에서 요청 |
| 추가 설정 | 주행 팝업: `adb shell appops set --user 10 <패키지> SYSTEM_ALERT_WINDOW allow` |
| 네트워크 | 필요 없음(빌드 시 의존성 다운로드 제외). TTS·LLM 모두 온디바이스 모드 |

### 알려진 제약 (에뮬레이터)
- 에뮬레이터 순정 내비에 지도 데이터가 없어 모의 주행 중 내비 위 차가 움직이지 않습니다. 경로 안내 시작까지는 동작합니다.
- 차량 화면에서 도착 알림이 내비 위 배너로 뜨지 않고 알림 목록에만 쌓입니다.
- 위치 권한 창의 문구가 "알 수 없는 작업"으로 나옵니다(플랫폼 문구).
- adb로는 한글을 입력할 수 없습니다. 닉네임은 화면 키보드로 입력해 주세요.
