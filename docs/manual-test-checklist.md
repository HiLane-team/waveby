# Waveby 수동 테스트 체크리스트

제출 전에 **release APK**(`apk/HiLane_Waveby_release.apk`)로 처음부터 끝까지 확인합니다.

- 테스트 날짜: ____________ / 확인한 사람: ____________
- 환경: Pleos Connect 에뮬레이터 v2.1.0, `emulator -avd Pleos_Connect_v2_1 -no-snapshot-load -memory 4096 -gpu host`

## 0. 준비
- [ ] 이전 설치본 삭제: `adb uninstall --user 10 com.drivepark.app` (처음 상태에서 시작)
- [ ] 설치: `adb install -r apk/HiLane_Waveby_release.apk`
- [ ] 주행 팝업 권한: `adb shell appops set --user 10 com.drivepark.app SYSTEM_ALERT_WINDOW allow`
- [ ] Virtual Console 연결: `adb forward tcp:8088 tcp:8088` → 브라우저에서 http://127.0.0.1:8088/ 열림
- [ ] 기어가 **P**인 상태에서 시작

## 1. 초기 설정 (첫 실행)
- [ ] 앱 목록에 **Waveby** 아이콘이 보이고, 누르면 메뉴 바 없이 초기 설정이 뜬다
- [ ] 위쪽 단계 점이 현재 단계를 길게 표시하고, "다음"/"이전"으로 옆으로 넘어간다
- [ ] **1단계 환영:** 늑대가 숨쉬고, "스쳐 지나간 차들의 캐릭터가 내 공원에 놀러와요"와 약속 문구가 보인다
- [ ] **2단계 권한:** 위치 "허용" → 시스템 창에서 허용 → "✓ 허용됨"으로 바뀐다
- [ ] 알림 "허용" → 허용 → "✓ 허용됨"
- [ ] 주행 팝업: appops로 켰다면 "✓ 허용됨". 꺼져 있으면 "이 차량에서는 아직 켤 수 없어요…" 안내가 보인다(버튼 없음)
- [ ] **3단계 누구의 캐릭터:** "나" 또는 "우리 집 반려동물"을 고르면 다음 단계로 넘어간다
- [ ] **4단계 캐릭터 만들기:** 모습·색·얼굴·모자·소품을 바꾸면 미리보기가 바로 바뀐다
- [ ] 닉네임이 **10자**에서 더 입력되지 않는다
- [ ] 인사말이 **30자**에서 더 입력되지 않는다
- [ ] 닉네임이나 인사말이 비어 있으면 다음 단계로 갈 수 없다
- [ ] **5단계 완료:** 캐릭터가 왼쪽에서 가운데로 걸어 들어오고 "공원으로" 버튼이 보인다
- [ ] "공원으로" → 왼쪽 메뉴 바(공원·친구·도감·설정)와 공원 화면
- [ ] 공원에 나와 공원지기 이호랑만 있고, 이호랑이 폴짝폴짝 뛰며 머리 위에 "나 좀 눌러 봐!" 말풍선이 보인다
- [ ] 이호랑을 누르면 처음 안내(6줄)가 시작되고, 화면을 누를 때마다 다음 줄로 넘어간다. "건너뛰기"로 바로 끝낼 수 있다
- [ ] 안내가 끝나면 이호랑이 공원 왼쪽 아래에서 놀고, 누르면 도움말 말풍선이 나온다

## 2. 시동 인사
- [ ] 앱을 완전히 종료한 뒤 다시 실행하면 시동 인사 화면이 뜬다
- [ ] 시간대에 맞는 인사말 + "○○님"(내 닉네임), 캐릭터 뒤 조명이 숨쉰다
- [ ] 아래에 "○○의 공원"이 보인다
- [ ] 약 3.5초 뒤, 또는 화면을 누르면 넘어간다
- [ ] 설정 "시동을 걸면"을 **내비**로 두면 인사 뒤 순정 내비가 뜬다(시동 한 번에 한 번)
- [ ] **공원**으로 두면 인사 뒤 공원에 머문다

## 3. 공원·친구·도감
- [ ] 공원에서 내 캐릭터가 걸어 다닌다
- [ ] 다크 테마에서 밤 공원으로 바뀐다
- [ ] 친구 탭: 친구가 없을 때 빈 화면이 어색하지 않다
- [ ] 도감 탭: "지역 캐릭터 도감 0 / 5"
- [ ] 위치 권한이 없으면 "위치 허용" 버튼이 보인다

## 4. 주행 → 주차 (핵심 흐름)
- [ ] Virtual Console에서 기어를 **D**로 바꾼다
- [ ] 순정 내비 위에 작은 주행 팝업이 뜨고, 내 캐릭터가 걷는다
- [ ] 팝업에 만난 사람 수가 **표시되지 않는다**
- [ ] 팝업이 내비 터치를 가로막지 않는다(팝업 자리의 지도가 눌린다)
- [ ] 주행 중 Waveby를 앞으로 열면 "주행 중이라 공원을 볼 수 없어요" 잠금 화면이 뜬다
- [ ] 1~2분 주행한 뒤 기어를 **P**로 바꾼다
- [ ] 팝업이 사라진다
- [ ] 친구가 있으면 "도착했어요!" 창이 뜨고 도착 인사 음성이 나온다
- [ ] 친구가 0명이고 새 지역도 없으면 조용히 끝난다(창·음성 없음)
- [ ] "공원 보기" → 공원에 새 친구가 보인다
- [ ] 친구 메뉴에 새 친구 수 배지가 뜨고, 친구 탭을 열면 배지가 사라진다
- [ ] 알림 목록에 도착 알림이 있다
- [ ] 글레오 브리핑을 켠 상태에서도 약 3초 안에 정해진 문장으로 음성이 나온다(에뮬레이터는 온디바이스 LLM이 꺼져 있음)

## 5. 지역 도감
- [ ] `adb emu geo fix 127.98 37.49`(횡성)로 옮긴 뒤 D → P
- [ ] 도착 창에 "횡성의 한우 음메롱"이 보인다
- [ ] 도감이 1 / 5로 올라간다
- [ ] 같은 지역에서 다시 주차하면 새 지역으로 다시 뜨지 않는다

## 6. 설정
- [ ] **캐릭터 바꾸기 "수정":** 바꾼 내용이 공원과 시동 인사에 반영된다
- [ ] **테마** 시스템/라이트/다크: 바로 바뀐다
- [ ] 시스템은 차량 다크모드 설정을 따른다
- [ ] **잠깐 사색에 잠기기** 켬 → D → P 하면 친구가 오지 않는다(지역은 계속 모인다)
- [ ] 공원 화면의 사색 토글과 설정 스위치가 같은 상태를 보인다
- [ ] **도착 알림** 끔 → 주차해도 알림이 안 쌓인다
- [ ] **인사 음성** 끔 → 주차해도 음성이 안 나온다
- [ ] **주차 10분 뒤 공원 안내:** 켬 → P에서 내비를 띄우고 10분 뒤 내비 위에 안내 박스("공원에 친구들이 놀고 있어요")가 뜬다. [공원 보기] → 공원 화면, × → 닫힘, 그냥 두면 15초 뒤 사라짐, 출발하면 바로 사라짐(빠른 확인은 개발자 메뉴 "공원 안내 시험 (5초)")
- [ ] 끔 → 안내 박스가 뜨지 않는다
- [ ] **데이터 초기화** → 확인 창 → "초기화": 친구·도감이 비고 내 캐릭터는 남는다
- [ ] "취소"를 누르면 아무것도 지워지지 않는다
- [ ] 앱을 껐다 켜도 설정값이 유지된다

## 7. 개발자 메뉴 (시연용)
- [ ] 설정 → 앱 정보의 "버전" 줄을 5번 누르면 개발자 메뉴가 열린다
- [ ] **드라이브 시뮬레이션 실행:** 3명 → 도착 창과 음성, "결과: 친구 3명 전달…"
- [ ] 0명 → "전달할 것이 없어 조용히 끝났어요"
- [ ] **순정 내비 모의 주행 (횡성):** 내비가 경로 안내를 시작하고 상태가 "주행(D)"
- [ ] **주차:** 주차 흐름이 실행된다
- [ ] **덮어쓰기 해제:** 실제 기어 상태로 돌아간다
- [ ] **음성 테스트:** "안녕하세요, 웨이브바이예요"가 들린다

## 8. Pleos 분할 화면
- [ ] 3분할의 좁은 칸에서 Waveby 화면이 잘리지 않고 좁은 배치로 바뀐다
- [ ] 분할 칸을 옮긴 뒤 앱을 다시 켜면 옮긴 자리를 기억한다
- [ ] 켜진 뒤에는 앱이 칸 위치를 계속 바꾸지 않는다

## 9. 안정성
- [ ] 주행 중 내비만 오래(10분 이상) 띄워 두어도, P로 바꾸면 도착이 정상 처리된다(앱이 얼지 않음)
- [ ] 화면 회전·다크모드 전환 중에 앱이 죽지 않는다
- [ ] `adb logcat | grep -i "FATAL"`에 Waveby 관련 오류가 없다

## 알려진 제약 (실패로 보지 않음)
- 에뮬레이터 순정 내비에 지도가 없어 모의 주행 중 내비 위 차가 움직이지 않음
- 도착 알림이 내비 위 배너로 뜨지 않고 알림 목록에만 쌓임
- 위치 권한 창 문구가 "알 수 없는 작업"(플랫폼 문구)
- adb로 한글 입력 불가 → 화면 키보드 사용
